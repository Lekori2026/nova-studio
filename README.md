# Workspace Starter

This project is a minimal web starter for a new workspace.

## Run it locally

```bash
npm start
```

Then open http://localhost:3000 in your browser.

## Files

- `index.html` — main page
- `styles.css` — styling
- `script.js` — small interaction
- `package.json` — scripts for starting the app

## Notes

This is intentionally lightweight so you can start building immediately.
